# Граница — научный атлас

Статический учебный сайт на русском языке для GitHub Pages. Парадоксы, математика, физические законы, космос и интерактивные математические эксперименты.

## Возможности
- 60+ редакционных вводных карточек, доступных офлайн после загрузки HTML/JS/CSS.
- Поиск по открытой энциклопедии (Wikipedia MediaWiki API, без ключа) с CORS `origin=*`.
- Порционная загрузка новых тем в четырёх категориях, запросы выполняются из браузера и требуют сети.
- Вводные выдержки из Википедии на экране темы, ссылки на полные статьи с атрибуцией CC BY-SA. Если API недоступен, показываются локальные описания.
- 7 самостоятельных лабораторий: Монти Холл, совпадение дней рождения, радиус Шварцшильда, аннигиляция вещества/антивещества, релятивистское замедление времени, теорема Пифагора, закон обратных квадратов.
- Встроенные вопросы с проверяемыми ответами для ряда тем.
- Два локальных профиля, закладки, пройденные темы, экспорт/импорт прогресса.
- Адаптивная верстка для смартфонов и десктопов.

## Локальный запуск
Откройте `index.html` в браузере. Для API-запросов удобнее локальный сервер: `python -m http.server 8000`.

## Опубликованная версия
Сайт размещён в папке `granitsa/` публичного репозитория `rymatoi/repos`, ветка `master`: https://rymatoi.github.io/repos/granitsa/ . Сборка GitHub Pages завершилась успешно.

Чтобы развернуть в другом репозитории, загрузите исходники в папку, доступную выбранному источнику Pages. В `Settings → Pages` выберите `Deploy from a branch`, нужную ветку и `/ (root)` (или `/docs` для соответствующей структуры). GitHub Pages должен быть включён владельцем репозитория.

## Ограничения
Это не автоматический генератор тысячи проверенных интерактивных уроков. Онлайн-материалы из Википедии — справочные статьи, не прошедшие отдельную редакционную экспертизу. Научные эксперименты используют явные упрощения. Профили хранятся в `localStorage` конкретного браузера, без синхронизации между устройствами и без серверного хранения. Импорт заменяет данные на устройстве.

Внешний API: https://www.mediawiki.org/wiki/API:Action_API (без токена). Числа физических констант взяты из стандартных справочных значений (CODATA/NIST, приближения). Код и оформление сайта написаны для этого проекта.
